# Elnouzalaa SaaS Platform

هذا هو المستودع الرئيسي (Monorepo/Root Directory) لمنصة النزلاء لإدارة وكالات السفر والسياحة. تم تنظيم هذا المشروع وفقاً لأفضل الممارسات الهندسية (Software Architecture Best Practices) لضمان قابلية التوسع (Scalability) وسهولة الصيانة (Maintainability).

## 📂 هيكلية المشروع (Project Structure)

تم تقسيم المشروع إلى المجلدات التالية لفصل الاهتمامات (Separation of Concerns):

- `/frontend` 🌐: سيحتوي على تطبيق الويب الخاص بالوكالات (مبني باستخدام Next.js و Tailwind CSS).
- `/backend` ⚙️: سيحتوي على الخادم البرمجي (API) والمنطق التشغيلي (سيتم بناؤه بـ Laravel أو NestJS).
- `/docs` 📚: يحتوي على وثائق المشروع مثل سياق المشروع (`PROJECT_CONTEXT.md`)، ومخططات قواعد البيانات، وتوصيف الـ APIs.
- `/infrastructure` 🏗️: سيحتوي على ملفات البنية التحتية، وأدوات النشر (CI/CD)، وإعدادات الخوادم السحابية.
- `/shared` 🔗: مجلد مقترح لأي موارد مشتركة قد نحتاجها مستقبلاً (مثل سكريبتات، تصاميم، أو إعدادات مشتركة).

## 🐳 تشغيل بيئة التطوير محلياً (Local Development Environment)

يحتوي الجذر الرئيسي على ملف `docker-compose.yml` مصمم لتشغيل قواعد البيانات المطلوبة للمشروع دون الحاجة لتثبيتها محلياً.

لتشغيل بيئة التطوير (تحتاج إلى تثبيت Docker على جهازك):
```bash
docker-compose up -d
```
هذا الأمر سيقوم بتشغيل:
1. **قاعدة بيانات PostgreSQL** (المنفذ 5432).
2. **قاعدة تخزين مؤقت Redis** (المنفذ 6379).
