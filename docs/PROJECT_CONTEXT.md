# سياق المشروع (Project Context) - منصة وكالات السفر (Elnouzalaa SaaS)

## 🎯 رؤية المشروع
تطوير منصة سحابية (B2B SaaS) متكاملة ومخصصة بالكامل لوكالات السفر والسياحة في الجزائر. تهدف المنصة إلى رقمنة وأتمتة العمليات اليومية للوكالات بدءاً من الحجوزات وإدارة العملاء، مروراً بتنظيم رحلات الحج والعمرة، وصولاً إلى النظام المالي، مما يقلل التدخل البشري ويضاعف الإنتاجية.

## 🧱 الوحدات الأساسية للمنصة (Core Modules)
1. **محرك الحجوزات (Booking Engine):** ربط مباشر مع Amadeus API لتذاكر الطيران، وإدارة حجوزات الفنادق والنقل.
2. **نظام الحج والعمرة:** إدارة المجموعات، متابعة التأشيرات (شنغن، عمرة)، وأرشفة الجوازات السحابية.
3. **نظام إدارة علاقات العملاء (CRM):** تصنيف العملاء، تتبع الاتصالات، وإرسال الإشعارات عبر WhatsApp API.
4. **النظام المالي وإدارة الخزينة (ERP):** الفواتير، الأقساط، سندات القبض/الصرف، ودعم بوابات الدفع الجزائرية (البطاقة الذهبية، CIB، BaridiMob).
5. **إدارة العمليات (HR & Operations):** إدارة الفروع، الصلاحيات (RBAC)، تقويم المواعيد، وتتبع مؤشرات الأداء.

## 💻 التقنيات المعتمدة (Tech Stack)
- **الواجهة الأمامية (Frontend):** Next.js (React.js) لدعم الأداء وتجربة المستخدم (SPA/SSR).
- **تصميم الواجهات (Styling):** Tailwind CSS + shadcn/ui.
- **الواجهة الخلفية (Backend):** Laravel (PHP) أو NestJS (Node.js) لدعم الـ Multi-tenancy والـ Microservices.
- **قواعد البيانات (Database):** PostgreSQL (الأساسية) + Redis (للتخزين المؤقت Queue & Caching).
- **التخزين (Storage):** Amazon S3 أو حلول مشابهة لتخزين الجوازات والمرفقات.

## 🎨 الهوية البصرية (UI/UX Guidelines)
- **مبدأ التصميم:** Mobile-First، تصميم عصري ونظيف يركز على سهولة الوصول للمعلومات.
- **الألوان الأساسية:**
  - أحمر جريء (Primary): `#DC2626` / Tailwind `red-600` (للأزرار والإجراءات الرئيسية).
  - رمادي داكن (Text & Menus): `#1F2937` / Tailwind `gray-800`.
  - أبيض ورمادي فاتح (Backgrounds): `#FFFFFF` و `gray-50` للتباين والمساحات السلبية.

## 🚀 خطة التطوير الأولية (MVP Roadmap - 4 Months)
- **الشهر 1:** البنية التحتية، تسجيل الدخول وتعدد الفروع، وواجهة CRM الأولية.
- **الشهر 2:** ربط Amadeus API وتطوير وحدة الحج والعمرة.
- **الشهر 3:** بناء النظام المالي، الأقساط، والربط مع الدفع الإلكتروني وWhatsApp.
- **الشهر 4:** اختبار الأمان، الاختبار التجريبي (Beta)، الإطلاق النهائي (Launch).
